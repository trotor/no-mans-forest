NO MAN'S FOREST
===============

A free, open-source WW2 squad tactics game — Finnish Continuation War, 1942.
https://github.com/trotor/no-mans-forest

Keep the "content" folder next to the game: it holds the maps, missions and art.

Windows
  Double-click NoMansForest.exe. If Windows SmartScreen warns about an unknown
  publisher, click "More info" and then "Run anyway" (the game is not signed).

macOS
  Double-click NoMansForest.app. The first time macOS may say it cannot check the
  app: open System Settings > Privacy & Security and click "Open Anyway", or
  right-click the app and choose Open. (The game is not notarised by Apple.)

Linux
  Run ./NoMansForest.x86_64 (if needed: chmod +x NoMansForest.x86_64 first).

In the game: F1 shows the controls. Esc opens the game menu.

-----------------------------------------------------------------------------

SUOMEKSI

Pidä "content"-kansio pelin vieressä: siinä ovat kartat, tehtävät ja grafiikka.

Windows: kaksoisnapsauta NoMansForest.exe. Jos SmartScreen varoittaa tuntemattomasta
julkaisijasta, valitse "Lisätietoja" ja "Suorita silti" (peliä ei ole allekirjoitettu).

macOS: kaksoisnapsauta NoMansForest.app. Jos macOS ei ensimmäisellä kerralla anna
avata sitä, avaa Järjestelmäasetukset > Tietosuoja ja turvallisuus ja valitse
"Avaa silti", tai napsauta sovellusta hiiren oikealla ja valitse Avaa.

Linux: käynnistä ./NoMansForest.x86_64 (tarvittaessa ensin chmod +x NoMansForest.x86_64).

Pelissä F1 näyttää ohjaimet, Esc avaa pelin valikon.
